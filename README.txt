حزمة PWA للعبة "من أنا؟"

الملفات: index.html + manifest.webmanifest + sw.js + مجلد icons

طريقة النشر (مجاناً):
1) Netlify: ادخل app.netlify.com/drop واسحب مجلد الحزمة (بعد فك الضغط).
2) أو GitHub Pages / Cloudflare Pages: ارفع الملفات كما هي في المجلد الرئيسي.

التثبيت:
- أندرويد (Chrome): افتح الرابط ثم "تثبيت التطبيق".
- آيفون (Safari): مشاركة ثم "إضافة إلى الشاشة الرئيسية".

ملاحظات:
- لازم الرابط يكون HTTPS حتى يشتغل التثبيت والعمل بدون إنترنت.
- عند تعديل الملفات غيّر رقم النسخة V في sw.js (مثلاً man-ana-v2) حتى يتحدث عند المستخدمين.
- خط Cairo يتحمل من الإنترنت أول مرة ويتخزن بعدها؛ بدونه يستخدم خط النظام.
